# KonspektAI — RAG-асистент для навчання

> Інтелектуальний чат-бот для роботи з навчальними матеріалами у форматі PDF з вбудованим квіз-режимом для самоперевірки знань.



**KonspektAI** — це веб-застосунок, розроблений на базі технології RAG *(Retrieval-Augmented Generation)*, що дозволяє студентам завантажувати конспекти у форматі PDF та отримувати відповіді на питання виключно на основі завантаженого матеріалу. Система не вигадує інформацію — вона відповідає лише тим, що є у конспекті.

Додатково реалізовано **квіз-режим**: AI автоматично генерує питання по завантаженому матеріалу, приймає відповідь студента і оцінює її правильність.



## Функціональні можливості

- **PDF-завантаження** — підтримка файлів до 50 МБ із автоматичним витягуванням тексту
- **RAG-чат** — відповіді суворо на основі завантаженого конспекту
- **Вільний чат** — режим без PDF для загальних навчальних питань
- **Квіз-режим** — автоматична генерація питань із трьома рівнями складності (Легка / Середня / Важка)
- **Перевірка відповідей** — AI аналізує відповідь студента і дає зворотній зв'язок
- **Підсумковий результат** — відсоток правильних відповідей після квізу
- **Вибір моделі** — підтримка кількох LLM через Groq API

| Компонент | Технологія |

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
https://github.com/FEDORONKO/KonspektAI.git
cd konspektai
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

**requirements.txt:**
```
streamlit>=1.28
groq>=0.4
python-dotenv>=1.0
pypdf>=4.0
PyPDF2
```

### 3. Налаштування API ключа


```env
GROQ_API_KEY=
```

### 4. Запуск застосунку

```bash
python -m streamlit run app.py
```

Застосунок відкриється у браузері за адресою: `http://localhost:8501`


Очікуваний результат:

```
API ключ знайдено!
Groq відповів: ...
PDF прочитано!
RAG працює!
ВСІ ТЕСТИ ПРОЙДЕНІ УСПІШНО!
```

## Як користуватись

1. Запустити застосунок командою `streamlit run app.py`
2. У боковому меню завантажити PDF-конспект
3. У режимі **Чат** — задавати питання по матеріалу
4. У режимі **Квіз** — обрати кількість питань і складність, пройти тест
5. Після квізу переглянути результат і відсоток правильних відповідей

## Архітектура RAG

```
PDF → Витягування тексту → Передача в контекст LLM → Відповідь
```

При кожному запиті система передає весь витягнутий текст конспекту як системний контекст моделі. Модель відповідає виключно на основі цього контексту, що унеможливлює генерацію неправдивої інформації поза межами матеріалу.
