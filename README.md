# 📚 EduMind RAG Assistant

**Персональний асистент для навчання на основі твоїх конспектів**

## 🎯 Що це?

EduMind - це розумний бот-тьютор, який використовує **RAG (Retrieval-Augmented Generation)** для того, щоб:
- 📖 **Запам'ятовувати** твої конспекти та методички
- ❓ **Відповідати** на питання виключно на основі твого матеріалу
- 🎓 **Готувати** тебе до екзамену через автоматичні квізи
- 📌 **Показувати** джерела відповідей

## 🚀 Швидкий старт

### 1️⃣ Встановлення

```bash
# Клонуємо проєкт
git clone https://github.com/FEDORONKO/edu_assistant.git
cd edu_assistant

# Встановлюємо залежності
pip install -r requirements.txt
```

### 2️⃣ Конфігурація

Створи файл `.env` та додай свій API ключ від Mistral:

```env
MISTRAL_API_KEY=your_key_here
```

[Як отримати ключ](https://console.mistral.ai/)

### 3️⃣ Запуск

```bash
streamlit run app.py
```

Додаток відкриється на `http://localhost:8501`

## 🎓 Як використовувати?

### Сценарій 1: Підготовка до екзамену

1. Завантажиш свої конспекти (PDF)
2. Задаєш питання про темати
3. Бот дає тобі відповідь з посиланням на вихідний матеріал
4. Повторюєш, поки не запам'ятаєш все

### Сценарій 2: Швидка перевірка знань

1. Натискаєш "Генерувати квіз"
2. Бот створює контрольні питання на основі твого матеріалу
3. Відповідаєш та перевіряєш себе

## 📊 Модельні параметри

| Параметр | Значення | Причина |
|----------|----------|---------|
| **Модель** | `mistral-small` | Швидка, дешева, точна |
| **Temperature** | `0.3` | Низька = факти, не креативність |
| **Top-K (RAG)** | `5 чанків` | Баланс точності та швидкості |
| **Chunk Size** | `1000 символів` | Оптимально для методичок |
